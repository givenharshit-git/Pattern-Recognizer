# AlgoPattern — Pattern Recognition Lab

A framework-free HTML/CSS/JavaScript learning dashboard generated from `PATTERN_RECOGNITION_GUIDE.txt`.

## Run

Open `index.html` directly in a modern browser.

## Features

- Technique dashboard
- Pattern-recognition library
- Search across problem title, number, pattern, difficulty and technique
- Difficulty / technique / progress filters
- Direct LeetCode links
- Solved and bookmark tracking using localStorage
- Progress dashboard
- Interactive decision guide
- Light/dark theme
- Responsive layout
- No framework, build step, backend or database

## Source

The app's problem dataset is parsed from the supplied guide (1433 source lines; 136 unique problem records extracted).

Files:
- `index.html`
- `styles.css`
- `script.js`
- `data.js`
